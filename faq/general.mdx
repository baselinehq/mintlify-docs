<AccordionGroup>
  <Accordion title="What is CostGraph?">
    A cost-optimization platform for Kubernetes and cloud VMs. It tracks your spend and resource usage and recommends rightsizing to cut cost.
  </Accordion>

  <Accordion title="What data does CostGraph collect?">
    Metrics and resource metadata only. No workload data, secrets, or logs leave your environment.
  </Accordion>

  <Accordion title="Should I use the operator or the agent?">
    The [operator](/costgraph/operator/overview) for Kubernetes clusters (installed with Helm), and the [agent](/costgraph/agent) for cloud virtual machines and bare metal (one shell command). Use both if you run both.
  </Accordion>

  <Accordion title="How does CostGraph attribute cost?">
    For Kubernetes, down to namespace, workload, and container. For VMs, at the instance level, split into CPU, memory, and storage. See [Cost attribution](/platform/cost-attribution).
  </Accordion>

  <Accordion title="How does billing work?">
    Pay-as-you-go, metered monthly by connected clusters, virtual machines, metrics-only agents, and Pricing and Chat API requests. See [Billing & plans](/platform/billing).
  </Accordion>
</AccordionGroup>
