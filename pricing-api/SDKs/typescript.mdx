## Client setup

```typescript
import { PricingApi, MarketplaceApi, Configuration } from '@baselinehq/pricingapi-client-typescript';
import type { Instance } from '@baselinehq/pricingapi-client-typescript';

const token = process.env.COSTGRAPH_API_KEY;

const config = new Configuration({
  basePath: 'https://pricing.baselinehq.cloud',
  apiKey: (name: string) => (name === 'X-API-Key' ? token : undefined),
});

const pricing = new PricingApi(config);
const marketplace = new MarketplaceApi(config);
```

## Compute pricing

```typescript
const instance: Instance = {
  region: 'nyc1',
  instance_type: 's-2vcpu-2gb',
  usage_type: 'ONDEMAND',
  provider: 'DigitalOcean',
  operating_system: 'linux',
  service: 'Droplet',
  vm: { cpu_cores: 2, ram_gb: 2 },
};

const price = await pricing.v1PricingComputePost(instance);
console.log(price.data.cost_per_hour);
```

const disk: Disk = {

  type: 'gp3',

## Marketplace

Publish your own rates. Re-posting the same natural key with a new cost keeps its id and reprices everything pinned to it.

```typescript
import type { ComputePricesRequest } from '@baselinehq/pricingapi-client-typescript';

const body: ComputePricesRequest = {
  entries: [{
    provider: '',
    service: 'compute',
    region: 'on-prem',
    instance_type: 'bare-metal-s',
    usage_type: 'ONDEMAND',
    operating_system: 'linux',
    cpu_cores: 64,
    ram_gb: 512,
    cost_per_hour: 2.5,
  }],
};

const published = await marketplace.v1MarketplaceComputePost(body);
const id = published.data.data?.[0]?.id;
```

List, patch, and retire:

```typescript
const page = await marketplace.v1MarketplaceComputeGet(100);

const updated = await marketplace.v1MarketplaceComputeIdPatch(id, { cost_per_hour: 3.0 });

await marketplace.v1MarketplaceComputeIdDelete(id);
```

The same five verbs exist for disks, databases, and models. A model patch retires the old row and returns the new id, because model prices are versioned.
