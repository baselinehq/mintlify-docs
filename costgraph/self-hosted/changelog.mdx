Releases of the `costgraph-selfhosted` chart. Published versions are in the [index.yaml](http://charts.costgraph.ai/index.yaml); release notes are on the [chart repository](https://github.com/BaselineHQ/costgraph-charts).

We publish a changelog for every minor release, and call out breaking changes in any release.

<Update label="2026-08-29" description="costgraph-selfhosted v0.4.1">
    Fixes an evaluation install: with the bundled database the backend did not start. Installs using your own Postgres were unaffected.
</Update>

<Update label="2026-08-29" description="costgraph-selfhosted v0.4.0">
    Install this or later. Each component is configured under its own key with a `deployment` block - see the [values reference](/costgraph/self-hosted/values). Earlier versions are superseded.
</Update>
