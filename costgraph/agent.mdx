# Costgraph Agent

The Costgraph Agent monitors process-level resource usage on your hosts. It collects CPU and memory metrics per process and exposes them via a Prometheus endpoint.

## How It Works

The agent runs on each host and collects per-process CPU and memory metrics, which are exposed at `http://localhost:9101/metrics`.

## Requirements

- Linux or macOS host
