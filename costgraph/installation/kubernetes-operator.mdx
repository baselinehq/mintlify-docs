# CostGraph Installation Guide

<Steps>
  <Step title="Install Prerequisites">
    Before you begin, ensure you have [Helm](https://helm.sh/docs/intro/install/) installed on your system.
  </Step>

  <Step title="Set up Prometheus">
    <Accordion title="Existing Prometheus installations">
    If you already have Prometheus running in your cluster, you can skip these installation steps and proceed directly to the next step.

    In your Helm `values.yaml`, set the `prometheus_endpoint` to your existing Prometheus URL.

    For example, if you're using the **kube-prometheus-stack**, the endpoint is typically:
    ```yaml
    prometheus_endpoint: http://kube-prometheus-stack-prometheus.kube-prometheus-stack.svc:9090
    ```
    </Accordion>

    Add the Prometheus chart repository:
    ```shell
    helm repo add prometheus-community https://prometheus-community.github.io/helm-charts
    ```

    Install Prometheus to begin collecting metrics:
    ```shell
    helm install prometheus prometheus-community/prometheus --namespace prometheus-system --create-namespace
    kubectl wait --for=condition=available --timeout=10m -n prometheus-system deploy/prometheus-server
    ```
  </Step>

  <Step title="Obtain API Key">
    Create an account on [costgraph.baselinehq.cloud](https://costgraph.baselinehq.cloud/) and obtain an [API key](https://costgraph.baselinehq.cloud/dashboard/api-keys).

    <img height="400" src="/images/api-key.png" />
  </Step>

  <Step title="Set up Billing Plan">
    <Warning>
    Setting up a plan

    You must have a plan setup for your organization to use the operator. Not doing so will cause the operator to fail on startup.
    </Warning>

    Once you have your API key, set up a billing plan to enable the API key.

    <img height="400" src="/images/billing.png" />
  </Step>

  <Step title="Add CostGraph Helm Repository">
    Add the CostGraph charts repository:
    ```shell
    helm repo add costgraph https://baselinehq.github.io/costgraph-charts/
    helm repo update
    ```
  </Step>

  <Step title="Configure CostGraph">
    Create a configuration file (`values.yaml`) with your specific settings:

    ```yaml
    domain: <your-company-subdomain>
    costgraph:
      config:
        costgraph_instance_name: <instance-name>
        prometheus_endpoint: <prometheus-address>
        api_key: <your-api-key>
    ```

    ### Optional Configurations

    **Multiple Cost Centers:**
    ```yaml
    costgraph:
      config:
        costgraph_instance_master_domains:
          - name: "<cluster-to-replicate-to>"
    ```

    **Expected Utilization Percentages:**
    ```yaml
    costgraph:
      config:
        expected_utilisation_percent:
          cpu: 80
          memory: 80
    ```

    **Superset Credentials:**
    ```yaml
    costgraph:
      config:
        superset_admin_username: admin
        superset_admin_password: admin
    ```

    **External Postgres (Optional):**
    <Warning>Postgres Configuration</Warning>
    Only use this if you have an existing postgres instance or manage a Postgres instance outside Kubernetes.

    ```yaml
    postgres:
      enabled: false
      config:
        postgres_db: postgres
        postgres_user: username
        postgres_password: password
        pg_data_directory: /var/lib/postgresql/data
        postgres_host: db_hostname
        postgres_port: db_port
    ```

    **Postgres PVC (Optional):**
    ```yaml
    postgres:
        pvc:
          enabled: true
          size: 10Gi
    ```
  </Step>

  <Step title="Deploy CostGraph">
    Deploy CostGraph using your configuration file:
    ```shell
    helm install costgraph costgraph/costgraph -f values.yaml
    ```
  </Step>

  <Step title="Verify Installation">
    Wait for all pods to be ready and verify the installation:
    ```shell
    kubectl get pods -n costgraph
    ```

    All pods should show a `Running` status before proceeding to access the dashboard.
  </Step>
</Steps>

## Accessing the Dashboard

You can access your cluster metrics in the [cluster section](https://costgraph.baselinehq.cloud/dashboard/cluster-metrics) of the CostGraph dashboard.
