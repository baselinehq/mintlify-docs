title: Virtual machines
description: "Inspect VM cost, utilization, metrics, and the containers running on each instance"

The Virtual Machines page under Compute lists every instance with its type and pricing model, CPU and memory utilization, runtime, cost, and rightsizing recommendation. Filter by status, provider, region, availability zone, or instance type.

<img src="/images/platform/virtual-machines.png" alt="Virtual Machines list with utilization, cost, and recommendation per instance" />

Open a VM for its detail tabs.

## Overview

System cost, instance details, agent status, and what's driving the load, the top processes and containers by usage.

<img src="/images/platform/vm-overview.png" alt="VM overview, system cost and what's driving the load" />

## Metrics

CPU, memory, network, disk, and filesystem over time, with a time range and a side-by-side comparison against another VM.

<img src="/images/platform/vm-metrics.png" alt="VM metrics, CPU, memory, network, and disk over time" />

## Containers

Every container on the instance, image, CPU and memory usage, uptime, and restarts.

<img src="/images/platform/vm-containers.png" alt="VM containers, running containers with CPU and memory usage" />
