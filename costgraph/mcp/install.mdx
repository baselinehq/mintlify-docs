You already debug your infrastructure inside a coding agent. CostGraph's MCP puts cost data, pricing, and recommendations right next to it.

## Prerequisites

- A CostGraph account with an active billing plan. For non-OAuth capable clients, an API key from [your account settings](https://app.costgraph.ai/settings/account/api-keys).

<Warning>
  MCP access requires an active billing plan. Set up billing in the [CostGraph platform](https://app.costgraph.ai/billing) before connecting.
</Warning>

<Note>
  Running headless or in CI, where a browser sign-in is not an option? Create an API key from [your account settings](https://app.costgraph.ai/settings/account/api-keys) and send it in the `X-API-Key` header instead, as shown in the tabs below.
</Note>

## Connect your agent through OAuth or API key

Pick your agent and drop in the config.

<Tabs>
  <Tab title="Codex" icon="/images/mcp/codex.svg">
    Add Costgraph to `~/.codex/config.toml` to sign in by using OAuth:
    ```toml
    [mcp_servers.costgraph]
    url = "https://mcp.costgraph.ai/mcp"
    
    [mcp_servers.example.oauth]
    client_id = "6peb1hopcd2bndd7rbn6e4vhed"
    callback_url = "http://127.0.0.1/callback"
    ```
    Or, with an API key:

    ```toml
    [mcp_servers.costgraph]
    url = "https://mcp.costgraph.ai/mcp"
    http_headers = { "X-API-Key" = "bl_your_key" }
    ```
  </Tab>
  <Tab title="Claude" icon="/images/mcp/claude.svg">
    On first connect, Claude Code opens your browser to sign in with your CostGraph account:
    
    ```bash
    claude mcp add --transport http \
      --callback-port 8080 \
      --client-id 6peb1hopcd2bndd7rbn6e4vhed \
    costgraph https://mcp.costgraph.ai/mcp
    ```

    Or run this and Claude Code registers the server with your API key.

    ```bash
    claude mcp add --transport http costgraph https://mcp.costgraph.ai/mcp \
      --header "X-API-Key: bl_your_key"
    ```
  </Tab>
  <Tab title="Amp" icon="/images/mcp/amp.svg">
    Add CostGraph to your Amp `settings.json`, with an API key:

    ```json
    {
      "amp.mcpServers": {
        "costgraph": {
          "url": "https://mcp.costgraph.ai/mcp",
          "headers": { "X-API-Key": "bl_your_key" }
        }
      }
    }
    ```
  </Tab>
  <Tab title="OpenCode" icon="/images/mcp/opencode.svg">
    Add Costgraph to your `opencode.json` to sign in by using OAuth:

    ```json
    {
      "$schema": "https://opencode.ai/config.json",
      "mcp": {
        "costgraph": {
          "type": "remote",
          "url": "https://mcp.costgraph.ai/mcp",
          "oauth": {
            "client_id": "6peb1hopcd2bndd7rbn6e4vhed"
            "redirect_uri": "http://127.0.0.1:19876/callback",
          }
        }
      }
    }
    ```

    Or, with an API key:

    ```json
    {
      "$schema": "https://opencode.ai/config.json",
      "mcp": {
        "costgraph": {
          "type": "remote",
          "url": "https://mcp.costgraph.ai/mcp",
          "headers": { "X-API-Key": "bl_your_key" },
          "enabled": true
        }
      }
    }
    ```
  </Tab>
  <Tab title="Generic" icon="plug">
    Generic MCP configuration. For OAuth-enabled sign in:
    ```json
    {
      "mcpServers": {
        "costgraph": {
          "url": "https://mcp.costgraph.ai/mcp",
          "client_id": "6peb1hopcd2bndd7rbn6e4vhed"
          "redirect_uri": "http://localhost:3335/callback"
        }
      }
    }
    ```

    Or, with an API key:

    ```json
    {
      "mcpServers": {
        "costgraph": {
          "url": "https://mcp.costgraph.ai/mcp",
          "headers": { "X-API-Key": "bl_your_key" }
        }
      }
    }
    ```
  </Tab>
</Tabs>

After it's connected, head to [Usage](/costgraph/mcp/usage) to put it to work.

## FAQ

<AccordionGroup>
  <Accordion title="Can the MCP change my infrastructure?">
    No. CostGraph is read-only over MCP. It hands back recommendations, pricing, and your inventory. Your agent, using its own git or kubectl access, is what actually applies a change or opens a PR.
  </Accordion>
  <Accordion title="Which credential does it use?">
    Interactive clients sign in with your CostGraph account and use a short-lived token that refreshes itself. Headless and CI setups send a `bl_` API key in the `X-API-Key` header. Either way, every read is scoped to your own tenant, so an agent only ever sees your data.
  </Accordion>
  <Accordion title="How do I revoke an agent's access?">
    Sign-in sessions are managed in your account settings, and revoking a session cuts off that client on its next token refresh. API keys can be deactivated or rotated at any time from [Settings](https://app.costgraph.ai/settings/account/api-keys).
  </Accordion>
  <Accordion title="What can my agent see?">
    Cost recommendations, live pricing, and your tenant's inventory and metrics. See [Usage](/costgraph/mcp/usage) for the kinds of questions that maps to.
  </Accordion>
</AccordionGroup>
