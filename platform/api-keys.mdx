---
title: API keys
description: "Create and scope API keys for the agent, operator, Pricing API, and MCP"
---

The Personal API Keys page under Settings creates and manages the `bl_` keys used for programmatic access. Select Create key to issue one.

<img src="/images/platform/api-keys.png" alt="Personal API Keys with scopes and tenant binding" />

Each key has:

- Scopes: Agent, Operator, or both, controlling what the key may do.
- Tenant: the workspace the key is bound to.
- Status and Last used.

Use a key when installing the [agent](/costgraph/agent#install) or [operator](/costgraph/operator/overview#install), or to authenticate the [Pricing API](/api-reference/introduction) and [MCP](/costgraph/mcp/install). Rotate or revoke a key from its row menu.
