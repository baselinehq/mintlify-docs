
The CostGraph Operator deploys and manages cost monitoring for your Kubernetes cluster. It collects resource usage metrics, analyzes spending patterns, and generates rightsizing recommendations — all visible from the [CostGraph dashboard](https://costgraph.baselinehq.cloud).

## Prerequisites

- A running Kubernetes cluster
- [Helm 3+](https://helm.sh/docs/intro/install/)
- An API key from the [CostGraph dashboard](https://costgraph.baselinehq.cloud/dashboard/api-keys)

## Quick Start

<Steps>

  <Step title="Add the Helm repository">
    ```shell
    helm repo add costgraph https://baselinehq.github.io/costgraph-charts/
    helm repo update
    ```
  </Step>

  <Step title="Install the operator">
    ```shell
    helm install costgraph-operator costgraph/costgraph-operator \
      --namespace costgraph \
      --create-namespace \
      --set global.clusterName=<your-cluster-name> \
      --set global.apiKey=<your-api-key>
    ```
  </Step>

  <Step title="Verify the installation">
    ```shell
    kubectl get pods -n costgraph
    ```

    All pods should show `Running` status. Once ready, view your cluster metrics in the [CostGraph dashboard](https://costgraph.baselinehq.cloud/dashboard/cluster-metrics).
  </Step>

</Steps>

## Customizing the Installation

For production deployments, create a `values.yaml` file instead of passing values inline.

```yaml values.yaml
global:
  clusterName: "production-cluster"
  apiKey: "<your-api-key>"
```

```shell
helm install costgraph-operator costgraph/costgraph-operator \
  --namespace costgraph \
  --create-namespace \
  -f values.yaml
```

### Authentication

You can pass your API key directly via `global.apiKey`, but for production we recommend using a pre-existing Kubernetes Secret.

```yaml values.yaml
global:
  clusterName: "production-cluster"
  existingSecret: "costgraph-api-key"
  existingSecretKey: "apiKey"   # key within the Secret, defaults to "apiKey"
```

Create the Secret beforehand:

```shell
kubectl create secret generic costgraph-api-key \
  --namespace costgraph \
  --from-literal=apiKey=<your-api-key>
```

### GPU Monitoring (DCGM Exporter)

<Note>
  The DCGM exporter is only needed if you want GPU metrics from NVIDIA GPU nodes. Most users can skip this section.
</Note>

Enable the NVIDIA DCGM exporter to collect GPU metrics:

```yaml values.yaml
dcgm-exporter:
  enabled: true
  nodeSelector:
    accelerator: nvidia
  tolerations:
    - key: nvidia.com/gpu
      operator: Exists
      effect: NoSchedule
```

### Chart Dependencies

The CostGraph Operator bundles several subcharts. If you already run any of these in your cluster, disable them to avoid conflicts.

| Dependency | Default | Purpose |
|------------|---------|---------|
| `kube-state-metrics` | Enabled | Kubernetes object-level metrics (pods, deployments, nodes) |
| `cadvisor` | Enabled | Container-level resource usage (CPU, memory, network) |
| `dcgm-exporter` | Disabled | NVIDIA GPU metrics |

To disable a bundled subchart:

```yaml values.yaml
kube-state-metrics:
  enabled: false

cadvisor:
  enabled: false
```

### Operator Components

The chart deploys two core components:

**Operator Kubernetes** (`operatorKubernetes`) — watches your cluster, collects Kubernetes metadata, and coordinates with the CostGraph backend.

**Operator Prometheus** (`operatorPrometheus`) — scrapes metrics from kube-state-metrics, cAdvisor, and DCGM exporter, then forwards them to the CostGraph TSDB via remote write.

Both run as single-replica deployments by default. You can customize resources, node selectors, tolerations, and environment variables for each. See the [Kubernetes configuration reference](/costgraph/configuration/kubernetes) for details.

# Default values for costgraph-operator.

# Global configuration shared across all operator components.

  clusterName: ""
  # apiKey is used to create a Secret when existingSecret is not set.
  # Do not commit a real key here; prefer existingSecret in production.
  apiKey: ""
  # existingSecret: name of a pre-existing Secret that contains the API key.
  # When set, no Secret is created by this chart and apiKey is ignored.
  existingSecret: ""
  # existingSecretKey: key within existingSecret that holds the API key value.
  # Defaults to "apiKey" when not specified.
  existingSecretKey: ""
  # backendURL is the base URL of the Costgraph API. Leave empty to omit the

nameOverride: ""
fullnameOverride: ""

serviceAccount:
  create: true
