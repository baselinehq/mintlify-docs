You already debug your infrastructure inside a coding agent. CostGraph's MCP puts cost data, pricing, and recommendations right next to it. On first connect your browser opens app.costgraph.ai: sign in with your CostGraph account if needed, pick a tenant, and approve.

## Prerequisites

- A CostGraph account with an active billing plan.

<Warning>
  MCP access requires an active billing plan. Set up billing in the [CostGraph platform](https://app.costgraph.ai/billing) before connecting.
</Warning>

## Connect your agent

Pick your agent and drop in the config.

<Tabs>
  <Tab title="Codex" icon="/images/mcp/codex.svg">
    Add CostGraph to `~/.codex/config.toml` to sign in by using OAuth:
    ```toml
    [mcp_servers.costgraph]
    url = "https://mcp.costgraph.ai/"
    ```
  </Tab>
  <Tab title="Claude" icon="/images/mcp/claude.svg">
    On first connect, Claude Code opens your browser to sign in with your CostGraph account:
    
    ```bash
    claude mcp add --transport http costgraph https://mcp.costgraph.ai/
    ```

  </Tab>
  <Tab title="Amp" icon="/images/mcp/amp.svg">
    Add CostGraph to your Amp `settings.json`:

    ```json
    {
      "amp.mcpServers": {
        "costgraph": {
          "url": "https://mcp.costgraph.ai/"
        }
      }
    }
    ```
  </Tab>
  <Tab title="OpenCode" icon="/images/mcp/opencode.svg">
    Add CostGraph to your `opencode.json` to sign in by using OAuth:

    ```json
    {
      "$schema": "https://opencode.ai/config.json",
      "mcp": {
        "costgraph": {
          "type": "remote",
          "url": "https://mcp.costgraph.ai/"
        }
      }
    }
    ```

  </Tab>
  <Tab title="Generic" icon="plug">
    Generic MCP configuration:
    ```json
    {
      "mcpServers": {
        "costgraph": {
          "url": "https://mcp.costgraph.ai/"
        }
      }
    }
    ```

  </Tab>
</Tabs>

After it's connected, head to [Usage](/costgraph/mcp/usage) to put it to work.

## FAQ

<AccordionGroup>
  <Accordion title="Can the MCP change my infrastructure?">
    No. CostGraph is read-only over MCP. It hands back recommendations, pricing, and your inventory. Your agent, using its own git or kubectl access, is what actually applies a change or opens a PR.
  </Accordion>
  <Accordion title="Which credential does it use?">
    Interactive clients sign in with your CostGraph account and use a short-lived token that refreshes itself. Headless or CI setups can use an API key from [Settings](https://app.costgraph.ai/settings/account/api-keys) sent in the `X-API-Key` header. Either way, every read is scoped to your own tenant, so an agent only ever sees your data.
  </Accordion>
  <Accordion title="How do I revoke an agent's access?">
    Every connected client is listed under [Settings > Connected apps](https://app.costgraph.ai/settings/account/connected-apps). Revoking one cuts off that client immediately.
  </Accordion>
  <Accordion title="What can my agent see?">
    Cost recommendations, live pricing, and your tenant's inventory and metrics. See [Usage](/costgraph/mcp/usage) for the kinds of questions that maps to.
  </Accordion>
</AccordionGroup>
