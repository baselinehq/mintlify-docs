## Install

```bash
go get github.com/baselinehq/pricingapi-client-golang@v1.0.0
```

The tag is the module version. Without one you get a pseudo-version pinned to a commit, such as `v0.0.0-20260904000608-ae60e4d9982f`.

## Client setup

```go
import (
    "context"
    "fmt"
    "os"

    openapiclient "github.com/baselinehq/pricingapi-client-golang"
)

configuration := openapiclient.NewConfiguration()
configuration.DefaultHeader["X-API-KEY"] = os.Getenv("COSTGRAPH_API_KEY")

client := openapiclient.NewAPIClient(configuration)
```

## Compute pricing

```go
instance := *openapiclient.NewInstance()
instance.SetInstanceType("s-2vcpu-2gb")
instance.SetUsageType("ONDEMAND")
instance.SetProvider("DigitalOcean")
instance.SetOperatingSystem("linux")
instance.SetService("Droplet")
instance.SetRegion("nyc1")

cpuCores := float32(2)
ramGb := float32(2)
instance.SetVm(openapiclient.GithubComBaselinehqGolangSharedTypesVM{
    CpuCores: &cpuCores,
    RamGb:    &ramGb,
})

price, _, err := client.PricingAPI.
    V1PricingComputePost(context.Background()).
    Instance(instance).
    Execute()

if err != nil {
    fmt.Fprintf(os.Stderr, "error: %v\n", err)
    return
}

fmt.Printf("Cost per hour: %v\n", price.GetCostPerHour())
```

## Disk pricing

```go
disk := *openapiclient.NewDisk()
disk.SetProvider("AWS")
disk.SetService("AmazonEBS")
disk.SetRegion("us-east-1")
disk.SetType("gp3")
disk.SetUsageType("ONDEMAND")
disk.SetCapacityGb(100)

price, _, err := client.PricingAPI.
    V1PricingDisksPost(context.Background()).
    Instance(*disk).
    Execute()
```

## Marketplace

Publish your own rates. Re-posting the same natural key with a new cost keeps its id and reprices everything pinned to it.

```go
entry := *openapiclient.NewComputePrice()
entry.SetProvider("") // claimed as your organization
entry.SetService("compute")
entry.SetRegion("on-prem")
entry.SetInstanceType("bare-metal-s")
entry.SetUsageType("ONDEMAND")
entry.SetOperatingSystem("linux")
entry.SetCpuCores(64)
entry.SetRamGb(512)
entry.SetCostPerHour(2.5)

body := openapiclient.NewComputePricesRequest([]openapiclient.ComputePrice{entry})

published, _, err := client.MarketplaceAPI.
    V1MarketplaceComputePost(context.Background()).
    Body(body).
    Execute()
```

List your rates, change one in place, retire it:

```go
page, _, err := client.MarketplaceAPI.
    V1MarketplaceComputeGet(context.Background()).
    Limit(100).
    Execute()

patch := map[string]any{"cost_per_hour": 3.0}
updated, _, err := client.MarketplaceAPI.
    V1MarketplaceComputeIdPatch(context.Background(), id).
    Body(patch).
    Execute()

_, err = client.MarketplaceAPI.
    V1MarketplaceComputeIdDelete(context.Background(), id).
    Execute()
```

The same five verbs exist for `Disks`, `Databases`, and `Models`. A model patch retires the old row and returns the new id, because model prices are versioned.
