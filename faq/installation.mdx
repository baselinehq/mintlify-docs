---
title: Installation
description: "Common questions about installing the operator and agent"
---

<AccordionGroup>
  <Accordion title="Does the operator install any CRDs?">
    No. It watches standard Kubernetes resources through the API, no custom resource definitions required.
  </Accordion>

  <Accordion title="Do I need an existing Prometheus?">
    No. The chart bundles kube-state-metrics, cAdvisor, and node-exporter. Disable any you already run in the cluster from the [configuration](/costgraph/operator/configuration).
  </Accordion>

  <Accordion title="Which platforms does the agent support?">
    Linux, Debian, Ubuntu, RHEL, Amazon Linux, and Alpine, on `amd64` or `arm64`. macOS via Homebrew is coming soon.
  </Accordion>

  <Accordion title="Can I pin a version?">
    Yes. For the agent, set `COSTGRAPH_AGENT_VERSION`, see the [changelog](/costgraph/agent/changelog) for available versions. The operator chart pins its images per release.
  </Accordion>

  <Accordion title="Which API key scope do I need?">
    An Operator-scoped key for the operator and an Agent-scoped key for the agent. Keys are bound to a workspace, see [API keys](/platform/api-keys).
  </Accordion>
</AccordionGroup>
