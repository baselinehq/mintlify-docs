Blacksmith runs managed GitHub Actions runners and bills the CI minutes they burn.

CostGraph reads Blacksmith as **FOCUS 1.2** records, one per org per day. When
Blacksmith serves usage without cost, the grain is one record per org per month.
See [What you get with an organization token](#what-you-get-with-an-organization-token).

## Before you begin

- Run `blacksmith org-token create` to create an organization token.
- Note the GitHub organization login exactly as GitHub shows it, including case.
  Blacksmith resolves the installation by the exact login, so `acmecorp` returns a 404
  where `AcmeCorp` succeeds.
- Optionally, find your price per billable minute on a recent Blacksmith invoice.

## What you get with an organization token

Blacksmith serves its own cost figures only to a signed-in dashboard session. An
organization token, which is what an unattended integration uses, reads usage but
not cost.

So CostGraph ingests your **billable minutes** per month, plus the free-minute
allowance. That is enough to track CI consumption and see how far past the free tier
you are running.

To turn those minutes into spend, supply your price per billable minute when you
connect. CostGraph multiplies it out and reports the result as cost. Leave it empty
and the minutes arrive with no cost attached, flagged so nothing reads them as free.

<Note>
CostGraph doesn't pick a rate for you. Blacksmith prices by runner size, and an
organization token can't read your runner mix. A default would be a number we
invented and reported as your spend.
</Note>

A blended rate from your invoice stays accurate while your runner mix holds. Revisit
it if you change runner sizes.

## Let CostGraph pull

1. Open **Settings > Integrations** and pick **Blacksmith**.
2. Name the connection and pick the tenant these charges belong to.
3. Enter the values you copied. The form lists what Blacksmith needs and marks the
   optional ones.
4. Select **Connect**.

CostGraph verifies the credentials with a short fetch before saving, so a wrong
value or a missing permission fails while you are still on the form.

<Note>
Credentials are encrypted at rest and used only to read billing data. Revoke them in
Blacksmith at any time and the connection stops; nothing else is affected.
</Note>

## Push it yourself

Send the charges to CostGraph as FOCUS records instead. [Push FOCUS data](/costgraph/integrations/focus-push) covers the connection id,
the `focus:write` key, and the request shape.

## Run the exporter

Rather than build that request yourself, run our exporter. It reads Blacksmith on a
schedule and pushes the records for you, wherever you want to run it: a container, a
Kubernetes `CronJob`, or a binary on a machine you already have.

```bash
focus-exporter --provider blacksmith --sink costgraph
```

Your Blacksmith credential stays where you put it, and only the finished FOCUS records
reach CostGraph. [Run the exporter](/costgraph/integrations/exporter) covers the three
ways to run it and the variables it reads.

## What CostGraph does with it

Records land as raw billing rows, are normalised into line items, and roll up into
daily cost. From there Blacksmith spend appears in Cost Overview and in anomaly
detection alongside every other provider, so runners billed for more than they
actually ran stand out as waste.

When only minutes are available, they chart as usage. A month that jumps well past
the free allowance surfaces the same way a cost spike does.
