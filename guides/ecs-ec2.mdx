---
title: Run the agent on AWS ECS (EC2)
description: "Install the CostGraph agent on the EC2 instances behind an ECS cluster"
---

With the EC2 launch type, your ECS tasks run on EC2 container instances that you manage. Install the CostGraph agent on those instances, not as a task, so it sees the whole host.

This does not apply to the Fargate launch type, which is serverless and gives no host access.

## Install on the container instances

ECS container instances are launched from a launch template by an Auto Scaling group. Add the install to the launch template's User data:

```bash
#!/bin/bash
curl -sSL https://setup.costgraph.ai/install.sh | COSTGRAPH_API_KEY="bl_..." sh
```

Keep the existing ECS bootstrap in the same User data (the line that writes `ECS_CLUSTER` to `/etc/ecs/ecs.config`) and append the install after it. Every new container instance the cluster launches then installs the agent.

## Verify

The container instances appear on the Virtual Machines page under Compute within a few minutes.

For configuration and other install methods, see the [agent reference](/costgraph/agent).
