---
title: Kubernetes Configuration
---

All CostGraph Operator configuration is managed through Helm `values.yaml`. This page documents every available option.

## Global Settings

<ParamField body="global.clusterName" type="string" required>
  The name of your Kubernetes cluster. Used to identify this cluster in the CostGraph platform.
</ParamField>

<ParamField body="global.apiKey" type="string">
  API key for authenticating with CostGraph. Do not commit real keys — use `existingSecret` in production.
</ParamField>

<ParamField body="global.existingSecret" type="string">
  Name of a pre-existing Kubernetes Secret containing the API key. When set, `apiKey` is ignored.
</ParamField>

<ParamField body="global.existingSecretKey" type="string">
  Key within `existingSecret` that holds the API key value. Defaults to `"apiKey"`.
</ParamField>

<ParamField body="global.backendURL" type="string">
  Base URL of the CostGraph API. Defaults to `"https://api.costgraph.ai"`.
</ParamField>

<ParamField body="global.namespace" type="string">
  Namespace for the operator. Defaults to `"costgraph"`.
</ParamField>

## Operator Kubernetes

The core operator component that watches your cluster and coordinates with the CostGraph backend.

<ParamField body="operatorKubernetes.enabled" type="boolean">
  Enable the Kubernetes operator. Defaults to `true`.
</ParamField>

<ParamField body="operatorKubernetes.image.repository" type="string">
  Container image repository. Defaults to `"ghcr.io/baselinehq/costgraph-operator-kubernetes"`.
</ParamField>

<ParamField body="operatorKubernetes.image.tag" type="string">
  Image tag.
</ParamField>

<ParamField body="operatorKubernetes.replicas" type="number">
  Number of replicas. Should always be `1`.
</ParamField>

<ParamField body="operatorKubernetes.resources" type="object">
  Kubernetes resource requests and limits.
</ParamField>

<ParamField body="operatorKubernetes.nodeSelector" type="object">
  Node selector for pod scheduling.
</ParamField>

<ParamField body="operatorKubernetes.tolerations" type="array">
  Tolerations for pod scheduling.
</ParamField>

<ParamField body="operatorKubernetes.affinity" type="object">
  Affinity rules for pod scheduling.
</ParamField>

<ParamField body="operatorKubernetes.env" type="array">
  Additional environment variables.
</ParamField>

## Operator Prometheus

Scrapes metrics from kube-state-metrics, cAdvisor, and DCGM exporter, then forwards them to the CostGraph TSDB.

<ParamField body="operatorPrometheus.enabled" type="boolean">
  Enable the Prometheus operator. Defaults to `true`.
</ParamField>

<ParamField body="operatorPrometheus.image.repository" type="string">
  Container image repository. Defaults to `"ghcr.io/baselinehq/costgraph-operator-prometheus"`.
</ParamField>

<ParamField body="operatorPrometheus.image.tag" type="string">
  Image tag.
</ParamField>

<ParamField body="operatorPrometheus.replicas" type="number">
  Number of replicas. Should always be `1`.
</ParamField>

<ParamField body="operatorPrometheus.config.remoteWriteURL" type="string">
  Remote write endpoint for metrics. Defaults to `"https://tsdb.costgraph.ai"`.
</ParamField>

<ParamField body="operatorPrometheus.config.remoteWritePath" type="string">
  Remote write path. Defaults to `"/api/v1/write"`.
</ParamField>

<ParamField body="operatorPrometheus.config.prometheusAPIProvider" type="string">
  Prometheus API provider type. Defaults to `"prometheus"`.
</ParamField>

<ParamField body="operatorPrometheus.config.httpTimeout" type="string">
  HTTP timeout for scrapes. Defaults to `"30s"`.
</ParamField>

<ParamField body="operatorPrometheus.config.cAdvisorNamespace" type="string">
  Override namespace for discovering cAdvisor pods. Leave empty to use the default.
</ParamField>

<ParamField body="operatorPrometheus.config.cAdvisorLabelSelector" type="string">
  Label selector for discovering cAdvisor pods.
</ParamField>

<ParamField body="operatorPrometheus.config.ksmNamespace" type="string">
  Override namespace for discovering kube-state-metrics pods.
</ParamField>

<ParamField body="operatorPrometheus.config.ksmLabelSelector" type="string">
  Label selector for discovering kube-state-metrics pods.
</ParamField>

<ParamField body="operatorPrometheus.config.dcgmNamespace" type="string">
  Override namespace for discovering DCGM exporter pods. Only relevant when `dcgm-exporter.enabled` is `true`.
</ParamField>

<ParamField body="operatorPrometheus.config.dcgmLabelSelector" type="string">
  Label selector for discovering DCGM exporter pods.
</ParamField>

<ParamField body="operatorPrometheus.resources" type="object">
  Kubernetes resource requests and limits.
</ParamField>

<ParamField body="operatorPrometheus.nodeSelector" type="object">
  Node selector for pod scheduling.
</ParamField>

<ParamField body="operatorPrometheus.tolerations" type="array">
  Tolerations for pod scheduling.
</ParamField>

<ParamField body="operatorPrometheus.env" type="array">
  Additional environment variables.
</ParamField>

## Subcharts

### kube-state-metrics

Provides Kubernetes object-level metrics (pods, deployments, nodes). Disable if you already run kube-state-metrics in your cluster.

<ParamField body="kube-state-metrics.enabled" type="boolean">
  Enable the kube-state-metrics subchart. Defaults to `true`.
</ParamField>

See the [upstream documentation](https://github.com/prometheus-community/helm-charts/tree/main/charts/kube-state-metrics) for all available options.

### cadvisor

Provides container-level resource usage metrics (CPU, memory, network).

<ParamField body="cadvisor.enabled" type="boolean">
  Enable the cadvisor subchart. Defaults to `true`.
</ParamField>

<ParamField body="cadvisor.image.registry" type="string">
  Image registry. Defaults to `"ghcr.io"`.
</ParamField>

<ParamField body="cadvisor.image.repository" type="string">
  Image repository. Defaults to `"baselinehq/cadvisor"`.
</ParamField>

<ParamField body="cadvisor.image.tag" type="string">
  Image tag. Defaults to `"0.56.3-baseline"`.
</ParamField>

### dcgm-exporter

<Note>
  Only enable this if you have NVIDIA GPU nodes and want GPU metrics.
</Note>

<ParamField body="dcgm-exporter.enabled" type="boolean">
  Enable the DCGM exporter. Defaults to `false`.
</ParamField>

<ParamField body="dcgm-exporter.serviceMonitor.enabled" type="boolean">
  Enable ServiceMonitor for Prometheus Operator. Defaults to `false`.
</ParamField>

<ParamField body="dcgm-exporter.nodeSelector" type="object">
  Node selector to restrict the DaemonSet to GPU nodes. Example: `{ accelerator: nvidia }`.
</ParamField>

<ParamField body="dcgm-exporter.tolerations" type="array">
  Tolerations for GPU node taints.
</ParamField>

<ParamField body="dcgm-exporter.resources" type="object">
  Kubernetes resource requests and limits.
</ParamField>

See the [upstream documentation](https://github.com/NVIDIA/dcgm-exporter/tree/main/deployment/chart) for all available options.
