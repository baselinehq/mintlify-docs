title: Virtual Machines
description: "Install the CostGraph agent on Linux VMs and bare-metal hosts"
---

Install the CostGraph agent on any Linux host with a single script, or run it in a container with Docker.

## Prerequisites

- A Debian, Ubuntu, RHEL, Amazon Linux, or Alpine host (or any Linux host, for Docker)
- An API key from the [CostGraph dashboard](https://app.costgraph.ai/settings/account/api-keys)

## Install

<Tabs>
  <Tab title="Script" icon="terminal">
    Pipe the installer to `sh` with your API key on the `sh` side of the pipe:

    ```bash
    curl -sSL https://setup.costgraph.ai/install.sh | COSTGRAPH_API_KEY="bl_..." sh
    ```

    Or download, inspect, then run:

    ```bash
    curl -sSL https://setup.costgraph.ai/install.sh -o install.sh
    chmod +x install.sh
    COSTGRAPH_API_KEY="bl_..." ./install.sh
    ```

    The installer supports Debian, Ubuntu, RHEL, Amazon Linux, and Alpine. It installs the latest stable release by default. Pin a specific release with `COSTGRAPH_AGENT_VERSION`, for example `COSTGRAPH_AGENT_VERSION=v0.0.63`.
  </Tab>
  <Tab title="Docker" icon="docker">
    <Tabs>
      <Tab title="Docker Compose" icon="layer-group">
        <Steps>
          <Step title="Create Compose File">
            Create a `docker-compose.yml` file with your configuration:

            ```yaml
            version: '3.8'
            services:
              costgraph-agent:
                image: ghcr.io/baselinehq/costgraph-agent:latest
                container_name: costgraph-agent
                restart: unless-stopped
                ports:
                  - "9090:9090"
                environment:
                  - API_KEY=your-api-key
                  - INSTANCE_NAME=my-vm
                  - PROMETHEUS_ENDPOINT=http://localhost:9090
                  - METRICS_PORT=9090
                  - LOG_LEVEL=info
                volumes:
                  - ./config:/etc/costgraph
                networks:
                  - costgraph-network

              # Optional: Add Prometheus for local metrics collection
              prometheus:
                image: prom/prometheus:latest
                container_name: prometheus
                restart: unless-stopped
                ports:
                  - "9091:9090"
                volumes:
                  - ./prometheus.yml:/etc/prometheus/prometheus.yml
                networks:
                  - costgraph-network

            networks:
              costgraph-network:
                driver: bridge
            ```
          </Step>

          <Step title="Start Services">
            Use Docker Compose to start the agent and related services:

            ```bash
            # Start all services
            docker-compose up -d

            # Check service status
            docker-compose ps

            # View logs
            docker-compose logs -f costgraph-agent
            ```
          </Step>

          <Step title="Verify Deployment">
            Check that all services are running correctly:

            ```bash
            # Check container status
            docker ps | grep costgraph-agent

            # Verify metrics endpoint
            curl http://localhost:9090/metrics

            # View logs for troubleshooting
            docker logs costgraph-agent
            ```
          </Step>
        </Steps>
      </Tab>
      <Tab title="Docker Run" icon="play">
        <Steps>
          <Step title="Prepare Configuration">
            Create your configuration file at `/etc/costgraph-agent/conf.yaml`:

            ```yaml
            api_key: "your-api-key-here"
            prometheus:
              enabled: true
              url: "https://your-prometheus-endpoint"
              write_path: "/api/v1/write"
              timeout: 10s
              interval: 60s
              tlsInsecure: false
              labels:
                env: "production"
            expected_utilisation:
              cpu: 60
              memory: 75
            ```
          </Step>

          <Step title="Run Container">
            Execute the Docker run command with proper configuration:

            ```bash
            docker run -d --name costgraph-agent \
              --restart=always \
              --pid=host \
              --net=host \
              -v /proc:/host/proc:ro \
              -v $(pwd)/etc/costgraph-agent:/etc/costgraph-agent:ro \
              -v $(pwd)/var/lib/costgraph-agent:/var/lib/costgraph-agent \
              --workdir /var/lib/costgraph-agent \
              ghcr.io/baselinehq/costgraph-agent:latest \
              costgraph-agent -conf /etc/costgraph-agent/conf.yaml
            ```
          </Step>

          <Step title="Verify Deployment">
            Check that the container is running correctly:

            ```bash
            # Check container status
            docker ps | grep costgraph-agent

            # Verify metrics are being collected
            curl http://localhost:9090/metrics

            # View container logs
            docker logs costgraph-agent
            ```
          </Step>
        </Steps>
      </Tab>
    </Tabs>
  </Tab>
</Tabs>

## Verification

The agent exposes metrics at `http://localhost:9101/metrics`. Once running, your host will appear in the [CostGraph dashboard](https://app.costgraph.ai/).
