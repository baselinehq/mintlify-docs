##  Configure CostGraph agent 

Similar to the CostGraph operator, the CostGraph agent supports additional configuration options for the agent deployment via `conf.yaml`.


## Quickstart

```yaml
prometheus:
  enabled:       true
  metrics_port:  9101
  url:           "http://localhost:9090"
  timeout:       10s 
  interval:      15s
  tenantHeader:  ""
  tenantValue:   ""
  bearerToken:   ""
  tlsInsecure:   false
  labels:
    job: costgraph-agent
expected_utilisation:
  cpu: 80
  memory: 80
api_key: ""
metrics_only: false
```

Assuming you have prometheus running within the same instance as the agent, you can use the configuration above. 

## Config reference 



<ParamField body="prometheus" type="object" required >
  Prometheus client configuration for the agent.
  
  <Expandable title="Prometheus Properties">
    <ParamField body="enabled" type="boolean">
      Whether the Prometheus client endpoint is exposed by the agent.
      
      Example: <CodeBlock>true</CodeBlock>
    </ParamField>

    <ParamField body="metrics_port" type="number">
      Port on which the agent exposes Prometheus metrics.
      
      Example: <CodeBlock>9101</CodeBlock>
    </ParamField>

    <ParamField body="url" type="string">
      Base URL of your Prometheus server that the agent queries for metrics.
      
      Example: <CodeBlock>"http://localhost:9090"</CodeBlock>
    </ParamField>

    <ParamField body="timeout" type="string">
      Request timeout when querying Prometheus, in duration format.
      
      Example: <CodeBlock>"10s"</CodeBlock>
    </ParamField>

    <ParamField body="interval" type="string">
      How often the agent queries Prometheus, in duration format.
      
      Example: <CodeBlock>"15s"</CodeBlock>
    </ParamField>

    <ParamField body="tenantHeader" type="string">
      Optional HTTP header name used for multi-tenant Prometheus setups (e.g., Cortex/Mimir). Leave empty if not required.
      
      Example: <CodeBlock>"X-Scope-OrgID"</CodeBlock>
    </ParamField>

    <ParamField body="tenantValue" type="string">
      Optional value for the configured tenant header. Leave empty if not required.
      
      Example: <CodeBlock>"acme"</CodeBlock>
    </ParamField>

    <ParamField body="bearerToken" type="string">
      Optional HTTP Bearer token used to authenticate to Prometheus.
      
      Example: <CodeBlock>""</CodeBlock>
    </ParamField>

    <ParamField body="tlsInsecure" type="boolean">
      Skip TLS certificate verification when connecting to Prometheus. 
      Example: <CodeBlock>false</CodeBlock>
    </ParamField>

    <ParamField body="labels" type="object">
      Arbitrary key/value labels attached to the agent's exported metrics and identity. Helpful for identifying instances when running a fleet of agents (e.g., per cluster, region, or host).
      
      <Expandable title="Labels Example">
        <CodeGroup>
          ```yaml
          labels:
            job: costgraph-agent
            cluster: prod-eu-1
            node: ip-10-0-1-23
          ```
        </CodeGroup>
      </Expandable>
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="expected_utilisation" type="object">
  Expected utilisation targets used to guide right-sizing recommendations.
  
  <Expandable title="Expected Utilisation Properties">
    <ParamField body="cpu" type="number">
      Target CPU utilisation percentage.
      
      Example: <CodeBlock>80</CodeBlock>
    </ParamField>
    
    <ParamField body="memory" type="number">
      Target memory utilisation percentage.
      
      Example: <CodeBlock>80</CodeBlock>
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="api_key" type="string" required>
  API key used by the agent to authenticate
  
  Example: <CodeBlock>"s34ko4k4-ksksokr3kgl-ok3krt4"</CodeBlock>
</ParamField>

<ParamField body="metrics_only" type="boolean">
  When enabled, the agent exports metrics only and skips recommendation. Useful if you only need observability or are running the agent in a metrics-forwarding mode.
  
  Example: <CodeBlock>false</CodeBlock>
</ParamField>
