---
title: Run the agent on AWS Elastic Beanstalk
description: "Install the CostGraph agent on Elastic Beanstalk's EC2 instances"
---

Elastic Beanstalk runs your application on EC2 instances that you control, so the CostGraph agent runs on them just like any other EC2 host. Install it on every instance with a platform hook.

This applies to Amazon Linux 2 and Amazon Linux 2023 platforms.

## Set the API key

Add your API key as an environment property, so the hook can read it without hardcoding it:

```bash
eb setenv COSTGRAPH_API_KEY=bl_...
```

You can also set it under Configuration, Software, Environment properties in the console.

## Add the install hook

In your application source, create `.platform/hooks/postdeploy/01_install_costgraph.sh`:

```bash
#!/bin/bash
API_KEY=$(/opt/elasticbeanstalk/bin/get-config environment -k COSTGRAPH_API_KEY)
curl -sSL https://setup.costgraph.ai/install.sh | COSTGRAPH_API_KEY="$API_KEY" sh
```

Deploy your application. Elastic Beanstalk runs the hook as root on every instance, including new ones added by scaling, so each installs the agent.

## Verify

The instances appear on the Virtual Machines page under Compute within a few minutes.

For configuration and other install methods, see the [agent reference](/costgraph/agent).
